# `routes/analytics.py`

## Призначення
Сторінка аналітики (`/admin/analytics`): загальна статистика по
студентах/групах/заповненості даних/якості оцінок, "перевірки
цілісності" (дублікати номерів диплома, розбіжність суми кредитів
тощо), детальний перегляд по конкретному студенту. Усі метрики
рахуються прямими SQL-запитами - навмисно не парсить `app.log` (ротація
файлу й зміна формату повідомлень з часом роблять такий парсинг
ненадійним для точної статистики).

## Взаємодія з app.py
Прямо: `from routes.analytics import analytics_bp` +
`app.register_blueprint(analytics_bp)`.

## Маршрути
- `GET /admin/analytics` - `dashboard()`: єдина сторінка з усіма
  розрізами. Не-адміністратор бачить статистику лише по своїх групах
  (`session['group_ids']`); загальносистемні розрізи - лише
  адміністратору чи користувачу з явним правом `analytics`.

## Залежить від
`routes.db`, `routes.utils` (`permission_required`).
