# `routes/db.py`

## Призначення
Єдина точка підключення до SQLite (`get_db()`) для всього застосунку,
плюс кастомна колація `UKRAINIAN` для коректного сортування українських
рядків прямо в SQL (`ORDER BY ... COLLATE UKRAINIAN`), оскільки типова
локаль `uk_UA.UTF-8` рідко встановлена на Windows-сервері за
замовчуванням.

## Взаємодія з app.py
**Не імпортується напряму в `app.py`.** Це найглибший, найбільш базовий
шар - його імпортує (через `from routes.db import get_db`) практично
кожен файл, що звертається до бази: усі підмодулі `routes/admin/*`,
`routes/students/*`, `routes/auth.py`, `routes/public_apply.py`,
`routes/public_update.py`, `routes/import_grades.py`,
`routes/analytics.py`, `routes/photo_bulk.py`, `routes/office_editor.py`
та `app.py` (лише один раз - усередині `inject_pending_counts()`, щоб
не тягнути зайвий імпорт нагору файлу заради однієї функції).

## Ключові функції
- `get_db()` - відкриває нове з'єднання з `students.db` (шлях
  обчислюється відносно розташування самого файлу, не поточної робочої
  директорії), вмикає `PRAGMA journal_mode=WAL` і
  `PRAGMA busy_timeout=30000` (щоб уникнути `database is locked` при
  паралельних запитах), реєструє функцію `LOWER_UA` (регістронезалежний
  пошук кирилиці) та колацію `UKRAINIAN`.
- `ukrainian_collation(a, b)` - функція порівняння рядків за українським
  алфавітом (враховує літери, яких немає в звичайному Unicode-порядку
  порівняння, напр. і/ї/й опиняються не там, де очікує звичайне
  сортування).

## Залежить від
Нічого зі `routes/*` - лише стандартна бібліотека (`sqlite3`, `logging`,
`locale`, `os`).
