# `routes/helpers.py`

## Призначення
Дрібні допоміжні функції, які раніше були продубльовані в кількох
файлах (`admin.py`, `students.py`, `auth.py`) - винесені сюди один раз,
щоб поведінка була гарантовано однаковою всюди (DRY).

## Взаємодія з app.py
**Не імпортується напряму в `app.py`.** Використовується практично
кожним файлом, що пише в журнал дій або сортує списки українською:
усі підмодулі `routes/admin/*` і `routes/students/*`, `routes/auth.py`,
`routes/photo_bulk.py`.

## Ключові функції
- `current_username()` - повертає ім'я користувача з поточної сесії для
  запису в `log_action(...)` (щоб у журналі дій завжди був консистентний
  формат імені, а не `session['username']`, розкиданий по коду).
- `sort_ukrainian(items, key_func)` - сортування списку словників/рядків
  за українським алфавітом на боці Python (для місць, де дані вже
  витягнуті з бази і сортувати через SQL `COLLATE UKRAINIAN` пізно).

## Залежить від
`locale` (стандартна бібліотека). Нічого зі `routes/*`.
