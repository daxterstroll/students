# `routes/students/__init__.py`

## Призначення
Пакетний "збирач" студентського блюпринта - той самий принцип, що й
`routes/admin/__init__.py`. Раніше весь функціонал жив в одному файлі
`routes/students.py` (~1750 рядків), тепер розбитий на 4 тематичні
підмодулі, кожен додає свої маршрути на той самий `students_bp`. Ім'я
ендпоінтів (`students.student_details`, `students.edit_student` тощо)
не змінилось - `url_for('students.xxx')` у шаблонах працює без правок.

## Взаємодія з app.py
Прямо: `from routes.students import students_bp` +
`app.register_blueprint(students_bp)`.

## Підмодулі
| Файл | Тема |
|---|---|
| `core.py` | Список/картка студента, додати/редагувати/видалити, фото, заморозка, періоди навчання, посилання на оновлення даних, генерація документа, FAQ |
| `military.py` | Військовий облік |
| `grades.py` | Виставлення оцінок (предмети й активності) |
| `import_export.py` | Масовий імпорт студентів з Excel |
