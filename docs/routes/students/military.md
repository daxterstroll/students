# `routes/students/military.py`

## Призначення
Військовий облік студента: один запис на студента (реєстраційний номер
ДРПВР, військово-обліковий документ, дата видачі, ВОС, звання, адреса
проживання тощо) + скановані копії документа (до 5 файлів, додавання/
перегляд/видалення окремого файлу).

## Взаємодія з app.py
Непряма (через `students_bp`, див. `routes/students/__init__.py`).

## Маршрути
`/students/<id>/military/add` (застарілий, не використовується з
картки студента - лишений для сумісності), `/students/<id>/military`
(основний CRUD - показує форму додавання, якщо запису ще нема, або
редагування, якщо є), `/students/<id>/military/delete_attachment`,
`/students/<id>/military/delete`.

## Залежить від
`routes.utils` (`get_attachments`, `save_multiple_attachments`).
