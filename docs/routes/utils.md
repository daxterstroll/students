# `routes/utils.py`

## Призначення
Найбільший спільний "інструментальний ящик" застосунку: логер, запис
дій у журнал, декоратори перевірки авторизації/прав доступу,
транслітерація ПІБ, робота з вкладеннями (`attachments`), логіка
скороченої програми навчання, пошук .docx-шаблонів.

## Взаємодія з app.py
**Не імпортується напряму (окрім `logger`)** - `app.py` робить
`from routes.utils import logger` (щоб `errorhandler(500)` міг
записати необроблену помилку в `app.log`) та використовує `format_grade`
опосередковано через `routes.gen_docx`. Усі інші функції звідси
імпортує майже кожен файл проєкту - це найбільш "розтягнутий" по
проєкту модуль.

## Ключові функції (за темами)
- **Логування:** `logger` (єдиний коректно налаштований логер - усі
  інші файли повинні писати саме через нього, а не голий
  `import logging`), `log_action(username, action, ...)` - запис рядка
  в `app.log` у стандартному форматі.
- **Авторизація:** `login_required(permission)`, `permission_required(permission)`
  - декоратори на маршрути; перевіряють сесію і права з
  `session['permissions']` / `session['is_admin']`.
- **Імена:** `transliterate_ukrainian(text)`, `generate_english_name(last, first)`
  - автоматичне англійське написання ПІБ (використовується при
  додаванні студента вручну, при імпорті, і в анкетах `/apply` та
  `/update-info`, щоб студент/абітурієнт не вводив латинку сам).
- **Вкладення:** `save_multiple_attachments(...)`, `get_attachments(...)`
  - спільна таблиця `attachments`, якою користуються накази, заморозка,
  документи про освіту, паспортні дані, військовий облік, заявки на
  реєстрацію/оновлення - завжди одним і тим самим кодом.
- **Скорочена програма:** `is_student_on_reduced_program(...)`,
  `program_track_condition(...)`, `apply_track_overrides(...)`,
  `filter_students_for_item(...)` - спільна логіка "цей предмет/практика
  видима для скороченої програми чи ні", використовується і в
  адмінських формах (`routes/admin/subjects.py`), і при виставленні
  оцінок (`routes/students/grades.py`), і в `routes/gen_docx.py`.
- **Шаблони документів:** `get_available_templates(...)`,
  `get_templates_with_metadata(...)` - список `.docx`-шаблонів із
  папки `template_word/`, відфільтрований за роллю користувача
  (адмінські шаблони бачить лише адмін).

## Залежить від
`routes.db` (опосередковано, через сигнатури функцій, які приймають
`conn`), стандартна бібліотека.
