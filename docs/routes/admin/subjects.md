# `routes/admin/subjects.py`

## Призначення
Предмети групи, практика/атестація/курсові (разом - "активності"),
масовий імпорт предметів з Excel. Усі три форми підтримують видимість
для скороченої програми (`full_program_only`/`reduced_only`,
окремі кредити/тип контролю для скороченої програми, якщо відрізняються).

## Взаємодія з app.py
Непряма (через `admin_bp`, див. `routes/admin/__init__.py`).

## Маршрути
- `/admin/manage_subjects` - CRUD предметів групи.
- `/admin/manage_activities` - CRUD практик/курсових/атестацій.
- `/admin/import_subjects` - імпорт з `.xlsx` (код/назва/кредити/тип
  + 3 необов'язкові колонки скороченої програми).

## Залежить від
`routes.utils` (`filter_students_for_item` - хто саме бачить цей
предмет при масовому виставленні оцінок), `openpyxl`,
`routes.admin.allowed_file` (перевірка розширення файлу імпорту).
