# `routes/admin/__init__.py`

## Призначення
Пакетний "збирач" адмінського блюпринта. Раніше весь адмінський
функціонал жив в одному файлі `routes/admin.py` (~5930 рядків) - тепер
розбитий на 7 тематичних підмодулів, кожен з яких лише ДОДАЄ свої
маршрути на той самий `admin_bp`, визначений тут. Завдяки цьому жодна
назва ендпоінта (`admin.manage_groups`, `admin.pending_students` тощо)
не змінилась - усі виклики `url_for('admin.xxx')` у ~30 HTML-шаблонах і
далі працюють без жодної правки.

## Взаємодія з app.py
Прямо: `from routes.admin import admin_bp` +
`app.register_blueprint(admin_bp)`. `app.py` не знає і не повинен
знати, що всередині `admin_bp` - пакет із 7 файлів, а не один модуль -
для Flask це один звичайний Blueprint.

## Що тут визначено
- `admin_bp = Blueprint('admin', __name__)` - спільний об'єкт, на який
  реєструються маршрути з усіх підмодулів.
- `allowed_file(filename)` - єдина спільна перевірка розширення файлу
  (`.xlsx`) для всіх імпортів з Excel (`subjects.py`, `documents.py`).
- Імпорти підмодулів у кінці файлу (`from . import catalogs` тощо) -
  саме вони реєструють маршрути; порядок імпорту значення не має.

## Підмодулі
| Файл | Тема |
|---|---|
| `catalogs.py` | Довідники (спеціальності, ступені, ліцензії, акредитації, дипломи) |
| `groups_courses.py` | Групи, курси, переведення, архів, випуск, відрахування |
| `subjects.py` | Предмети, практика/атестація/курсові, імпорт предметів |
| `documents.py` | Документи про освіту, паспортні дані, обидва імпорти |
| `applications.py` | Заявки на реєстрацію (`/apply`) і на оновлення даних (`/update-info`) |
| `users.py` | Користувачі, права, журнал дій |
| `templates_and_export.py` | Шаблони документів, масова генерація, вивантаження фото |
