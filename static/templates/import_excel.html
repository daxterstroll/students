Що робить імпорт
  • Знаходить наявного студента за student_id → tax_id → ФІО+дата → ФІО (тільки якщо збіг рівно один)
  • Готує нового студента з транслітерацією ПІБ (КМУ №55-2010)
  • Готує нове навчання (паралельне, реактивація з архіву, відновлення після відрахування)
  • Показує різницю по кожному полю: що було / що стане
  • Визначає стать — з колонки K або автоматично за по батькові
  • Показує прев'ю — ви вирішуєте, що застосувати
Військові дані з Excel не імпортуються. Вони заповнюються вручну на картці студента (розділ «Військові дані») або автоматично з PDF «Резерв+» — по одному (картка студента) чи пакетно (Імпорт → PDF «Резерв+» (пакетно)).

Два режими роботи

Режим визначається тим, чи заповнена колонка A (ID групи). Це дозволяє одним файлом і додавати нових студентів, і масово правити дані по вже наявній базі — без ризику зачепити навчання.

A заповнено — з групою
  • Новий студент → створиться + навчання
  • Є в іншій групі → паралельне навчання
  • Був відрахований/випущений → реактивується
  • Був в архіві → розархівується
  • Вже активний у цій групі → пропуск (дублікат)
  • + оновлення полів картки
A порожньо — тільки оновлення
  • Студент знайдено → оновлюються лише вибрані поля картки (телефон, email, ІПН, ЄДЕБО, адреса, стать)
  • Навчання, ліцензія, група, кредити, архів — не змінюються
  • Студент не знайдено → пропуск з поясненням «для нового група обов'язкова»
  • Колонка F (кредити override) ігнорується — немає прив'язки до групи
Порядок пошуку студента

Перший збіг «виграє» — наступні кроки не виконуються:

1. student_id (L) 2. tax_id (I) 3. ФІО + дата (B + C) 4. ФІО без дати*

* крок 4 виконується тільки якщо: (а) колонка A порожня (update-only режим); (б) колонка C порожня; (в) знайдено рівно одного студента з таким ПІБ. Якщо знайдено 2+ — рядок пропускається з підказкою «уточніть дату народження, ІПН або student_id».

Базові колонки A–K
# Колонка Обов'язкова Приклад / Формат
A ID групи Умовно 1 — числовий ID групи. Порожньо = режим «тільки оновити» (без створення навчання).
B ПІБ повністю Так Шевченко Іван Олександрович — рівно 3 слова через пробіл
C Дата народження Ні 15.03.2001 або клітинка Excel з форматом ДД.ММ.РРРР. Порожньо — пошук за ФІО (тільки якщо збіг один).
D Код ЄДЕБО Ні 12345678
E Ліцензія Ні Львівська — коротка назва з каталогу «Ліцензії», без урахування регістру
F Кредити скороченої програми Ні 180 — менше за програму групи. Ігнорується, якщо A порожня.
G Телефон Ні +380991234567, +380991234568 — основний[, резервний] через кому
H Email Ні student@example.com
I ІПН (РНОКПП) Ні 1234567890 — зберігається як рядок
J Адреса Ні м. Львів, вул. Шевченка 1, кв. 5
K Стать Ні Ч/Ж/M/F — або порожньо (авто за по батькові)
Опціональні колонки L–N

Керують пошуком і поведінкою при знайденому студенті. Можна залишити порожніми — тоді діють налаштування за замовчуванням.

# Колонка За замовчуванням Приклад / Формат
L student_id — 1234 — прямий ID студента в БД. Найнадійніший спосіб влучити саме в потрібного студента (пріоритетніший за tax_id та ФІО).
M is_primary auto 1 — зробити цю групу основною. 0 — не змінювати. Порожньо: для нового студента група стає основною; для існуючого — не змінюється. (Застосовується разом з новим enrollment у прев'ю.)
N update_existing_data 1 1 (або порожньо) — у прев'ю будуть показані поля картки для оновлення. 0 — поля не показуються (тільки навчання).
Коли рядок позначається як помилковий (пропускається)
  • ПІБ містить не рівно 3 слова
  • A вказана, але ID групи не існує, заархівована або недоступна користувачу
  • Студент вже активно навчається в цій групі (дублікат)
  • A порожня, а студента не знайдено в базі («для нового група обов'язкова»)
  • A порожня, C порожня, і з таким ПІБ знайдено 2+ студентів (уточніть дату/ІПН/student_id)
  • Вказано неіснуючий student_id у колонці L
