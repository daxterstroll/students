Формат файлу

Перший рядок — заголовки (ігноруються). Дані починаються з рядка 2.
Колонки A-D обов'язкові й у фіксованому порядку. Колонки E-G — необов'язкові, для студентів на скороченій програмі (можна лишити порожніми для звичайних предметів).

# Колонка Обов'язкова Приклад / Формат
A Код предмету Так ОП.01 — унікальний в межах групи
B Назва предмету Так Українська мова
C Кількість кредитів Так 3 — ціле число, мінімум 1
D Тип підсумкового контролю Так Залік або Екзамен — точно так, з великої літери
Скорочена програма (колонки E-G) — усі необов'язкові.
E Видимість Ні Порожньо або всі — предмет для всіх; повна — лише для повної програми; скорочена — лише для скороченої
F Кредити для скороченої Ні 10 — лише якщо відрізняються від звичайних кредитів (колонка C)
G Тип для скороченої Ні Залік або Екзамен — лише якщо відрізняється від звичайного типу (колонка D)
{# Причины пропуску рядка #}
Коли рядок пропускається
  • Будь-яке з полів A-D порожнє
  • Предмет з таким кодом вже існує в обраній групі
  • Тип контролю відрізняється від Залік або Екзамен
  • Кількість кредитів менше 1 або не є числом

Некоректне значення в колонках E-G (напр. невідома видимість) не пропускає рядок — просто це конкретне поле ігнорується, а попередження показується після імпорту.
