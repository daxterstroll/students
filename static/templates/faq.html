Як заповнити додаток до диплома: покрокова інструкція

Порядок важливий: кожен наступний крок спирається на дані попереднього. Якщо якийсь крок уже виконано раніше (наприклад, група вже створена) — просто перевірте його і йдіть далі.

Одноразове налаштування каталогів (перед першою групою нової спеціальності/ступеня/року): Спеціальність має бути в переліку на сторінці «Спеціальності» (зі скороченою назвою — інакше групу не створити), ступінь — на «Ступені», а для конкретного року вступу мають бути додані «Освітня програма» і «Назва кваліфікації» саме для цієї трійки «спеціальність + ступінь + рік». Якщо чогось із цього ще немає — створення групи заблокується з поясненням, куди піти й додати відсутнє. Один раз налаштувавши, наступного року для тієї самої спеціальності лишається додати хіба що новий рік вступу в «Освітню програму»/«Назву кваліфікації».
Про ліцензії (нова модель): ліцензія тепер — властивість конкретного навчання (пари «студент + група»), а не всього студента. Один студент може паралельно вчитися в кількох групах під різними ліцензіями, і в кожному документі, згенерованому для конкретної групи, буде підставлена саме її ліцензія.
1
Створіть/перевірте групу — Навчання → Групи
Вручну вводите лише: рік вступу, форму навчання, кредити, ступінь (зі списку), спеціальність (зі списку), найменування та статус закладу (зі списку), вимоги до вступу, результати навчання (кожен пункт з нового рядка), «програма включає» (кожен пункт з нового рядка).
Решта підставляється автоматично (поля лише для читання): курс, назва групи, англійські версії спеціальності/галузі знань/ступеня/закладу, освітня програма й назва кваліфікації (укр.+англ.) — за парою/трійкою «спеціальність + ступінь + рік вступу».
2
Додайте студента — Студенти → Додати студента (або Імпорт з Excel для цілої групи)
ПІБ українською та англійською (транслітерація підставляється автоматично — перевірте написання за закордонним паспортом!), дата народження, код ЄДЕБО, група, ліцензія для першого навчання.
3
Додайте предмети групи — Навчання → Предмети (або Імпорт предметів)
Для кожного предмета: код, назва укр., назва англ., кредити. Порядок у списку = порядок рядків у таблиці додатка.
4
Додайте практики, курсові та атестацію групи — Навчання → Практика / атестація / курсові
Так само: код, назви обома мовами, кредити. Атестація має окреме поле теми роботи для кожного студента (заповнюється на кроці 6).
5
Виставте оцінки з предметів — Картка студента → Оцінки (або одразу для всієї групи: Навчання → Імпорт оцінок (зведена відомість))
Також з цих оцінок автоматично обчислюється «Диплом з відзнакою» (не менше 75% оцінок «A», жодної «D»/«E», атестація на «A»).
6
Виставте оцінки за практики / курсові / атестацію — Картка студента → Практика та атестація
Оцінки за кожну активність + тема кваліфікаційної роботи для атестації.
7
Додайте попередній документ про освіту — Документи та накази → Документи освіти (або Імпорт документів)
Тип документа (укр.+англ.), номер, заклад (укр.+англ.), країна, дата завершення. Для іноземних документів — додатково блок довідки та визнання.
8
Призначте номери диплома і додатка — Документи та накази → Номери диплому / додатку
Номер диплома і номер додатка окремо для кожної групи студента (система сама доповнює їх нулями до 6 цифр).
9
Перевірте акредитацію — Система → Акредитації
Запис із текстом акредитації (укр.+англ.) для пари «ступінь + спеціальність» вашої групи.
10
Згенеруйте документ — Картка студента → Генерувати документ → шаблон додатка
Якщо студент навчається у кількох групах — спершу оберіть групу, для якої генеруєте документ. Далі відкриється попередній перегляд з можливістю редагування прямо в браузері, і «Завершити і завантажити». Для цілої групи одразу: Студенти → Масова генерація документів.

{% if has_perm('manage_students') %}

Список усіх студентів з пошуком за ПІБ, фільтром по групі та індикаторами заповненості. Не-адміністратори бачать лише студентів своїх груп. Звідси відкривається картка студента — центральна точка для всіх подальших дій із конкретною людиною.
Фільтр «Ліцензія» — показує студентів, які мають хоч один активний enrollment під цією ліцензією. Студент, що вчиться одночасно під Львівською і Польською, знайдеться в обох фільтрах. Пункт «— без ліцензії —» показує студентів, чиї enrollments ще не мають проставленої ліцензії.
Паралельне навчання: якщо студент вчиться у двох і більше групах — біля основної групи бейдж «+N» із підказкою, у яких ще групах він перебуває.
Заповненість: смужка «особисті дані» + значки статусу (червоний — не все заповнено, зелений — повністю): фото, оцінки, практика/курсові/атестація, військові дані, паспортні дані, документ про освіту.
Військова заповненість залежить від статусу: «Військовозобов'язаний»/«Резервіст» — 14 полів, «Призовник» — 9, «Знято з обліку» — 8.

Є 3 основні сценарії, коли людина вже фігурує в базі й хоче навчатися ще.

Сценарій A: поступає на другу спеціальність, продовжуючи першу
  1. На сторінці «Студенти» знайдіть цього студента (пошук за ПІБ або ІПН).
  2. Відкрийте картку → блок «Навчання (групи)» → кнопка «Додати паралельне навчання».
  3. Виберіть нову групу + ліцензію + заповніть номер і дату наказу про зарахування.
  4. Статус: у студента буде 2 активні enrollments. Основна група не змінюється.
Сценарій B: повертається після відрахування
  1. Знайдіть студента (він у базі, але в архіві).
  2. Відкрийте картку → блок «Навчання (групи)» → «Додати паралельне навчання» з номером і датою наказу про поновлення.
  3. Студент автоматично знімається з архіву.
Сценарій C: друга вища освіта після випуску
  1. Студент уже в базі, стара група в архіві, стара enrollment має статус graduated.
  2. Відкрийте картку → блок «Навчання (групи)» → «Додати паралельне навчання» з номером/датою нового наказу про зарахування.
  3. Опційно — поставте галочку «Зробити цю групу основною».
Загальне правило: у картці студента одна людина = одна картка, скільки б груп у неї не було. Ніколи не створюйте нового студента з тим самим ІПН.

Як називати файли

  • Прізвище Ім'я По-батькові.jpg — найточніший
  • Ім'я Прізвище.jpg — порядок слів не важливий
  • Прізвище І.П..jpg — за ініціалами
Кілька схожих студентів — оберете вручну

Якщо у файлі «Вовчук Оксана.jpg», а в базі двоє — система не вгадає. Такий рядок буде позначено кілька кандидатів, а під випадаючим списком з'являться кнопки для ручного вибору.

Автоматична обрізка 3×4 — навколо обличчя
  • без бейджа — знайдено одне обличчя;
  • без обличчя — обличчя не знайдено. Обов'язково перевірте й виправте вручну.
  • N фото — на скані знайдено кілька однакових облич. Система обрала одне — найближче до центру аркуша.

Відомі обмеження (де потрібна особлива увага)

Ці місця працюють коректно для паралельного навчання, але мають обмеження, які варто знати:

  • Редагування наявного документа про освіту з загального списку — не показує дропдаун «Для якої групи». Щоб змінити прив'язку — відкрийте документ через картку студента.
  • Study periods із group_id = NULL — показуються в усіх групах студента. Рекомендується прив'язати їх до конкретної групи в картці студента.
  • Архівування групи вручну — позначає архівними лише студентів, для яких ця група основна.
  • Історія змін військових даних на сторінці військових даних показує лише останні 200 змін. Повна історія — в /admin/view_logs.
  • Об'єднання наказів — не можна скасувати. Решта наказів, крім головного, видаляються назавжди.
