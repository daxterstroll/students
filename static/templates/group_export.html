Один пакет = один документ на студента. Якщо студент одночасно вчиться у двох (або більше) групах, йому потрібно окремий документ для кожної групи, адже предмети, диплом, ліцензія, освітня програма й навіть періоди навчання в кожній групі — свої.
Що генерується за різних фільтрів:
Фільтр Для якої групи буде документ
Обрано групу A Для групи A — навіть якщо в студента основна група інша. У документ підтягнуться предмети, диплом, ліцензія й періоди навчання саме з A.
Обрано групу B Для групи B. Той самий студент, але тепер з даними B.
Обрано лише рік народження (без групи) Для основної групи кожного студента (primary enrollment). Для паралельної групи документ так не згенерується.
Обрано окремих студентів галочками Для тих, кого відмітили, з тією самою логікою визначення групи, що й вище.
Як отримати документи для обох груп одного студента
  1. Запустіть масову генерацію з фільтром «Група A» — отримаєте ZIP з документами для A.
  2. Поверніться на цю сторінку.
  3. Запустіть масову генерацію з фільтром «Група B» — отримаєте окремий ZIP з документами для B.

Це дві різні сесії генерації — з різними наборами даних у документах. Обидві можна редагувати в ONLYOFFICE незалежно, як і будь-який інший пакет.

Що НЕ потрапить у документ помилково: предмети з іншої групи, диплом із іншої групи, ліцензія з іншої групи — усе це тепер береться з тієї групи, під яку ви фільтрували. Якщо студента з паралельним навчанням не видно у списку — це означає, що він не має активного навчання в обраній групі; його можна додати в картці студента (розділ «Навчання (групи)»).
